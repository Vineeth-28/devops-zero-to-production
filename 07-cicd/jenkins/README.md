## Learning Path

1. **Day 11 — Fundamentals**: install, master/agent architecture, plugins, security basics
2. **Day 12 — Jobs & Pipelines**: Freestyle jobs, Declarative vs Scripted pipelines, Jenkinsfile syntax
3. **Day 13 — GitHub Integration**: webhooks, credentials, multibranch pipelines, PR builds
4. **Day 14 — Jenkins + Docker**: Docker agents, building/pushing images, Docker-in-Docker
5. **Day 15 — Production Jenkins**: HA, backup/restore, shared libraries, RBAC, scaling agents
