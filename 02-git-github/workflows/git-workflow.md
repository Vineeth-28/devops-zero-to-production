# Git Workflow

```text
Edit File

↓

Working Directory

↓

git add

↓

Staging Area

↓

git commit

↓

Local Repository (Snapshot)

↓

git push

↓

Remote Repository (GitHub)
```

## Key Idea

Working Directory → Everything you changed

Staging Area → Everything you want to commit

Commit → Snapshot saved by Git

Push → Upload commits to remote repository
