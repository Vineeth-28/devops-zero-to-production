Customer reports:

```
Website takes 20–30 seconds to load.
```

# Common Causes

- High CPU usage
- High memory usage
- Heavy application workload
- Traffic spike
- Infinite loop
- Expensive database queries

# Engineering Mindset

Never assume.

Collect evidence first.

# Key Takeaway

Slow servers require investigation, not guesswork.
