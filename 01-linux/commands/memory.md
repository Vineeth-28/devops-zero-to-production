# 🧠 Linux Memory Management

## What is Memory?

Memory (RAM) stores data required by running applications.

Low available memory can make applications slow or unstable.

---

# Commands

## Check Memory Usage

```bash
free -h
```

Purpose:

Displays total, used, free and available memory.

---

## Real-Time Memory

```bash
top
```

Shows memory usage by running processes.

---
